## 8. Pro Tip 💡

Use **Medium compression** for documents that will be read on screen, and **High compression** only for files that will just be archived or stored — not printed. High compression reduces image resolution inside the PDF, which looks fine on a monitor but can appear slightly soft if someone prints it on A3.

Also: if you're compressing a PDF that you then need to merge with another document, do the compression first, then use **PDFForge Merge PDF** to combine them. Compressing after merging a large file takes longer in-browser, so order matters.

## 9. Common Mistakes to Avoid

**Using High compression on a document meant for printing** — High mode targets images aggressively. For print-quality output, stick to Low or Medium. The file size difference is worth more than you'd think even on Low.

**Compressing an already-compressed PDF and expecting big results** — If someone already ran a PDF through a compressor, compressing it again won't give you dramatic size reduction. You're already near the floor. This isn't a PDFForge limitation — it's just how PDF compression works.

**Forgetting to check the output before sending** — Always open the compressed file once before emailing it. Edge cases like unusual fonts or vector graphics can sometimes render differently after heavy compression. Takes 10 seconds to check and saves an embarrassing re-send.

## 10. FAQ

**Does compressing a PDF damage the text or make it unreadable?**
Text in PDFs is stored as vector data, not images — compression doesn't affect it at all. Only embedded images get reduced. Typed text, headings, and formatted content come out identical.

**Can I compress a scanned PDF (where pages are images)?**
Yes, and this is actually where PDFForge compression makes the biggest difference. Scanned PDFs are essentially image files inside a PDF wrapper — compressing them can cut file size dramatically, sometimes by 60–70%.

**Will the compressed PDF still be editable?**
If your original PDF was editable (fillable form fields, selectable text), the compressed version keeps that. Compression targets image data, not the document structure.

**Is there a limit to how much compression can achieve?**
Yes — there's a floor. A PDF with no embedded images (like a pure text document) won't compress much because there's no image data to reduce. A 500KB text-only PDF might come down to 480KB. That's normal.
