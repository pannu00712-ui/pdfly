How to rotate pages in a PDF

  1. Drop your PDF into the tool above, or click to browse your device.
  2. Choose whether to rotate all pages or specific pages by number or range.
  3. Select your rotation angle (90°, 180°, or 270°) and click "Rotate PDF" to download instantly.

How PDFly rotates PDF pages

PDFly uses the pdf-lib library to apply rotations to your PDF pages. Here's how it works:

  • Lossless rotation: The rotation is applied as a metadata transformation — the content itself is not re-rendered or re-encoded, so there's no quality loss.
  • Page-level control: You can rotate all pages at once, or target specific pages using page numbers and ranges.
  • Cumulative rotation: If a page already has a rotation applied, the new rotation is added to the existing rotation (e.g., 90° + 90° = 180°).
  • Preserved content: All text, images, form fields, links, and bookmarks remain intact — only the page orientation changes.

When to rotate PDF pages

  • Fixing scanned documents: Scanned pages often come in sideways or upside down — rotate them back to the correct orientation.
  • Mixed orientation documents: Some pages in a PDF may be portrait while others are landscape — rotate individual pages to match.
  • Viewing convenience: Rotate pages to the preferred reading orientation before sharing or printing.
  • Presentation preparation: Ensure all slides or pages are oriented consistently for presentations.

Page number formats you can use

  • Single page: 3 — rotates only page 3
  • Range: 5-10 — rotates pages 5 through 10
  • Multiple: 1, 3, 5-7, 12 — rotates pages 1, 3, 5, 6, 7, and 12

Understanding rotation angles

  • 90° CW (Clockwise): Rotates the page 90 degrees to the right. Use for pages that are rotated 90° counter-clockwise.
  • 180°: Flips the page upside down. Use for pages that are completely inverted.
  • 90° CCW (Counter-clockwise): Rotates the page 90 degrees to the left. Use for pages that are rotated 90° clockwise.

Before you rotate

  • Check the orientation: Make sure you know which pages need rotation and in which direction.
  • Count carefully: Double-check your page numbers before clicking Rotate. PDF page numbering starts at 1.
  • Unlock first: If the PDF is password-protected, use Unlock PDF first.
  • Keep a backup: Save a copy of the original file in case you need to revert.

Common mistakes

  • Entering page numbers that don't exist (e.g., page 20 in a 10-page document).
  • Using spaces incorrectly — 1- 5 doesn't work; use 1-5.
  • Rotating all pages when only one or two need fixing.
  • Deleting the original before checking that the rotated PDF opens correctly.

Troubleshooting

  • The rotation didn't apply to the pages I selected: Double-check your page numbers and range format. The preview shows page numbers as you type.
  • The PDF won't open after rotation: Some PDFs use features that pdf-lib can't fully preserve. Try Repair PDF on the original first, then rotate.
  • I rotated the wrong direction: Upload the original file again and rotate it back using the opposite angle (e.g., 90° CW to fix a 90° CCW mistake).
  • Some pages are still the wrong orientation: Check if those pages have existing rotations that are being added to your new rotation. Try rotating by a different angle.
