How to remove a watermark from a PDF

  1. Drop your PDF into the tool above, or click to browse your device.
  2. Navigate to each page using the page controls. Draw a rectangle over the watermark you want to remove.
  3. Click "Remove Watermarks & Download" to get a clean PDF. Everything runs in your browser — nothing is uploaded.

How PDFly removes watermarks

PDFly's watermark remover works by rendering each page as an image, then replacing the selected area with white. This approach is simple and effective for watermarks on white or light-colored backgrounds.

The tool uses pdf.js to render the PDF pages, and pdf-lib to rebuild the final PDF. All processing happens locally in your browser — your file data never leaves your device.

Types of watermarks that can be removed

  • Text watermarks: "DRAFT", "CONFIDENTIAL", "SAMPLE" — easy to remove on white backgrounds.
  • Simple logos: Solid-color logos on white or light backgrounds clean up well.
  • Page numbers: Can be removed if they appear in consistent positions.
  • Stamp overlays: "RECEIVED", "PAID", "COPY" stamps are good candidates.

Limitations and considerations

  • Background matters: Works best on white or light backgrounds. On dark or colored backgrounds, the white replacement may stand out.
  • Complex watermarks: Watermarks that are transparent, gradient, or overlaid on images may leave visible artifacts.
  • Text becomes images: Because the tool renders pages as images, text in the cleaned PDF won't be selectable. This is a necessary trade-off for watermark removal.
  • File size increase: The cleaned PDF is typically larger than the original because pages are saved as images. Use Compress PDF if you need a smaller file.

Before you remove a watermark

  • Check permissions: Only remove watermarks from PDFs you own or have permission to modify.
  • Unlock first: If the PDF is password-protected, use Unlock PDF first.
  • Keep a backup: Always keep the original file in case you need to revert.

Common mistakes

  • Drawing rectangles too small — make sure the box fully covers the watermark.
  • Expecting perfect removal on dark or colored backgrounds — white fill will be visible.
  • Deleting the original before checking the cleaned PDF opens correctly.
  • Removing watermarks that are actually part of the document content (like headers or footers).

Troubleshooting

  • The watermark is still visible: Try drawing a slightly larger rectangle to ensure full coverage of the watermark area.
  • The cleaned PDF looks pixelated: The tool renders at a high resolution (2× scale) for export. If you need higher quality, try using a desktop PDF editor.
  • The file is very large after cleaning: Use Compress PDF to reduce the file size.
  • Pages appear blank or missing: Some PDFs use fonts or features that pdf.js can't render — try a different tool or desktop software for complex PDFs.
