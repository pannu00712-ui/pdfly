How to edit PDF metadata online

  1. Drop your PDF into the tool above, or click to browse your device.
  2. Update the Title, Author, Subject, Keywords, or Creator fields as needed.
  3. Click "Save & Download with Updated Metadata" to get your file. Nothing is uploaded; everything happens in your browser.

Why edit PDF metadata?

A PDF's metadata — its title, author, subject, keywords, and creator fields — controls how the file appears in search results, browser tabs, and document management systems. Outdated or missing metadata can make files harder to find, misattribute authorship, or leak details you didn't intend to share, like the name of the software or person who created the file.

PDFly edits metadata directly in your browser, so the PDF never leaves your device. There's no account to create, no watermark, and no software to install. It works on Windows, Mac, Linux, Android, and iPhone using any modern browser.

Best Practices & Limitations

Tips for best results

  • Fill in Title and Author fields for documents you'll share widely — it improves how they display in file browsers and search results.
  • Clear metadata before sharing a document externally if the original file history shouldn't be visible.
  • Keep metadata consistent across a document set (same author/organization name) for a more professional look.

Limitations & when not to use this tool

  • Edits the PDF's document properties, not any text visible on the pages themselves.
  • Doesn't remove metadata embedded in images placed inside the PDF (like camera EXIF data) — those need separate handling.
  • Some custom/proprietary metadata fields added by other software may not be visible or editable here.

Frequently asked questions

Which metadata fields can I edit?

You can edit the title, author, subject, keywords, and creator fields stored in the PDF's document properties.

Does editing metadata change the PDF's content or layout?

No. Only the document properties are updated — the pages, text, and formatting stay exactly as they are.

Can I clear a metadata field instead of replacing it?

Yes. Leave a field empty before saving and that property will be removed from the PDF.

Is my PDF uploaded anywhere?

No. Metadata is read and rewritten entirely in your browser, so the file never leaves your device.
