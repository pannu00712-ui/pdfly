PDF Conversion Tools

Convert files to and from PDF — documents, spreadsheets, slides, images, and more — free and without installing anything.

PDF is the format most files end up in once they're finished, but it's rarely the format they start in or the one you need to edit them further. Converting between PDF and other file types is one of the most common tasks on the web, and it usually comes down to one of two directions: turning an editable file like a Word document, spreadsheet, or slide deck into a fixed PDF for sharing, or converting a PDF back into an editable format so it can be updated.

For document conversion, Word to PDF and PDF to Word cover the most common pair, preserving formatting in both directions so a converted document still looks like the original. The same applies to spreadsheets and slides: Excel to PDF and PDF to Excel handle spreadsheets, while PowerPoint to PDF and PDF to PowerPoint do the same for presentations. If you just need the words, PDF to Text and Text to PDF strip away formatting entirely in either direction.

Image conversions are just as common: JPG to PDF and PNG to PDF turn photos or scanned pages into a shareable document, while PDF to JPG and PDF to PNG extract pages as standalone images for use elsewhere, like a slide or a webpage. HTML to PDF converts a webpage into a fixed, printable document, and for ebooks, EPUB to PDF and PDF to EPUB move files between the two most common ebook and document formats.

All conversions run free with no daily limit, no account, and no watermark added to the output. Most conversions happen locally in your browser using the same engines that power desktop software, so files typically aren't uploaded to a remote server in the process. If you're not sure which specific conversion you need, the tool cards below cover the most requested pairs, and each links through to a full how-to guide with more detail on formatting, quality, and file size.
