How to Remove Pages From a PDF: Delete Unwanted Content Instantly

By Alex Rivera · Updated July 2026 · 6 min read

You've got a 50-page PDF. Pages 1-45 are the document you need. Pages 46-50 are blank, or they're duplicates, or they're from another document entirely. You don't want to delete the whole PDF — you just want to get rid of those last few pages.

Removing pages from a PDF is one of the most common tasks, yet many tools make it complicated. With the right tool, it's as simple as selecting pages and clicking delete.

It's an easy step to overlook, yet it's important — seems trivial but becomes frustrating when you use the wrong tool. Some tools force you to delete pages one by one. Others make you re-export the PDF without the unwanted pages. A good tool makes it effortless.

Why pages need to go

There are many reasons you might need to remove pages from a PDF:

  • Blank pages: Often from scanning, where the scanner added extra pages. This is especially common with double-sided scanning.
  • Duplicates: When merging files, you might end up with duplicate pages. This happens when you merge files that already contain the same content.
  • Unwanted sections: You don't need the appendix, or you only want the first few chapters. Removing pages is faster than extracting.
  • Printing errors: Pages that didn't print correctly and need to be removed. This saves you from re-printing the entire document.
  • Sensitive information: Pages with confidential data that shouldn't be in the shared version. Sometimes redaction isn't enough — you need to remove the whole page.

There's also a less obvious use case: reducing file size. If you remove several pages, the file size decreases. This can be helpful if you're trying to get a PDF under an email attachment limit.

How to remove pages without the hassle

You don't need to open the PDF in an editor and scroll through page by page. A dedicated tool lets you remove pages with a few clicks.

One advantage of using a dedicated tool over opening the PDF in an editor is that you can remove pages without rendering the document first. This is faster and works with more PDFs.

How to select pages to remove

Most tools offer several ways to select pages:

  • Individual pages: Select specific page numbers like 2, 5, 12. This is useful when you have a few pages to remove.
  • Ranges: Select a range like 10-20 (removes pages 10 through 20). This is useful when you want to remove a section.
  • Combinations: You can mix and match — "1, 3, 5-10, 15." This gives you full control.
  • Visual selection: Some tools let you click on thumbnails to select pages. This is intuitive but slower for large documents.

The range syntax is worth learning. "10-20" removes pages 10 through 20. "10-" removes from page 10 to the end. "-10" removes from the beginning to page 10. These shortcuts can save time.

Remove pages vs. extract pages

These two tools serve different purposes:

  • Remove Pages: Deletes pages from the original PDF. You end up with a smaller version of the same file.
  • Extract Pages: Creates a new PDF with only the pages you select. The original file stays unchanged.

Use Remove Pages when you want to trim the original document. Use Extract Pages when you want to save a subset as a separate file.

The choice depends on what you need. If you're cleaning up a document and never want to see the removed pages again, use Remove Pages. If you're sharing a subset but want to keep the original intact, use Extract Pages.

Frequently Asked Questions

Can I remove multiple pages at once from a PDF?

Yes — you can select individual pages, ranges, or combinations like "1, 3, 5-10, 15" to remove multiple pages at once.

Does removing pages reduce the PDF file size?

Yes — removing pages will reduce the file size proportionally, since you're deleting content from the file.

Can I undo a page removal?

Most tools don't have an "undo" button. It's a good idea to keep a copy of the original file before removing pages.
