How to Extract Pages From a PDF: Save Only What You Need

By Alex Rivera · Updated July 2026 · 6 min read

You've got a 200-page PDF. You only need pages 45-52 — but you don't want to delete the rest, because you might need them later. What you really need is to extract those pages into a new, separate PDF.

Extracting pages is different from removing pages. When you extract, you create a new PDF with only the pages you selected, and the original file stays untouched. It's perfect for sharing a subset of a document without giving away the whole thing.

It's easy to overlook this option entirely — many people don't realize it's available. They assume they have to either send the entire file or delete pages and save a new version. Extraction gives you a third, more flexible option.

When to extract pages

  • Sharing: Send only the relevant pages to a client or colleague.
  • Archiving: Save a section of a document for future reference.
  • Presentations: Extract slides from a larger deck.
  • Printing: Print only the pages you need without wasting paper.

There's also a less obvious use case: combining content from multiple documents. You can extract pages from several different PDFs and then merge them into a new document. This is common in legal work, where you might need to assemble exhibits from various source documents.

Extract vs. split vs. remove

These three tools are often confused. Here's the difference:

  • Extract: Creates a new PDF with selected pages. Original stays the same.
  • Split: Breaks one PDF into multiple files. Everything is divided.
  • Remove: Deletes selected pages from the original. The file becomes smaller.

Use extract when you want to create a new file from a subset of pages. Use split when you want to divide the whole document. Use remove when you want to delete pages from the original.

The distinction is important because the tools have different outputs. Extract gives you one new file. Split gives you multiple files. Remove gives you one file that's smaller than the original. If you use the wrong one, you might end up with more files than you wanted or lose content you needed.

What gets preserved in extraction

When you extract pages, the content, formatting, and quality of the pages are preserved exactly as they were in the original. The only difference is that you have fewer pages.

This is because extraction is essentially a copy operation. The tool takes the raw page data from the original file and writes it into a new file. It doesn't compress, convert, or modify the pages in any way. This means the extracted PDF is identical to the original in every way except page count.

One practical implication: if the original file had interactive elements like bookmarks or hyperlinks, they may or may not survive the extraction. Some tools preserve them, others don't. If interactivity matters, it's worth checking.

Frequently Asked Questions

Can I extract non-consecutive pages?

Yes — you can select individual pages like "2, 5, 12, 17" or combine ranges like "2-5, 12-17."

Does extracting pages affect the original file?

No — the original file remains untouched. Extracting creates a completely new file.

Can I extract pages from a scanned PDF?

Yes — extraction works with any PDF, including scanned ones, since it just copies the pages as they are.
